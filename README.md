## Tema

**Análise de Acidentes de Trânsito no Brasil**

O projeto utiliza uma base de dados simulada contendo informações sobre acidentes de trânsito em diferentes regiões, estados e cidades do Brasil, entre os anos de 2015 e 2024.

## Objetivo

O objetivo é explorar os dados de acidentes de trânsito e identificar padrões relacionados a:

- distribuição dos acidentes por região e estado;
- tipos de acidente mais frequentes;
- períodos do dia com maior número de ocorrências;
- evolução temporal dos acidentes;
- relação entre chuva e acidentes;
- influência da visibilidade;
- identificação de registros graves e críticos.
